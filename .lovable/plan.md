# 可行性评估 + 建站方案：数据分析求职作品集单页

## 结论：整体完全可行

第 9 条（移除平台角标）按你的要求去掉，不再作为需求。其余 9 条全部 100% 可满足。

## 逐条可行性

| 约束 | 可行性 | 说明 |
| --- | --- | --- |
| 1 纯静态、无后端 | 可行 | 不启用任何后端能力，纯前端页面 |
| 2 无任何外链 | 可行 | 全站不出现 http(s) 外部链接与相关导航文案 |
| 3 无第三方脚本/统计 | 可行 | 不引入任何分析 SDK |
| 4 无表单/订阅 | 可行 | 页脚只有静态文字 |
| 5 仅站内锚点 | 可行 | 导航用 #hash + 平滑滚动 |
| 6 仅本人姓名与学校 | 可行 | 只出现「鲜芳慧 / 广东财经大学」，无其他人名与隐私信息 |
| 7 单页滚动 | 可行 | 只用首页一个路由，无子页面 |
| 8 无在线看板嵌入 | 可行 | 证据区用本地占位图，无 iframe |
| 9 移除 Lovable 角标 | 部分 | 预览环境的编辑角标由平台注入，无法在代码里删除；发布后的站点角标可在发布设置里关闭（需你在发布时确认）。我会保证页脚自身不含任何平台链接 |
| 10 noindex 元标签 | 可行 | 在页面 head 注入 `noindex, nofollow`，并同步把 robots.txt 改为 Disallow: /（当前默认允许抓取） |

一个技术提醒：字体需通过 head 的 link 加载（不能在 CSS 里 @import 远程地址），这属于必要的静态资源引用，不算「外链导航」；如果你希望连字体请求也完全没有，我改用系统无衬线字体栈。

## 页面结构（单页，自上而下）

1. 顶部极简导航：首页 / 项目 / 能力 / 方法 / 证据（锚点，滚动高亮）
2. Hero：大标题「数据分析方向候选人」+ 2–3 行简介 + 姓名/学校 + 抽象数据可视化装饰（纯 CSS/SVG 绘制，无外部图）
3. 项目板块：淘宝用户行为分析，含定位、数据规模、技术栈、五个分析模块卡片（流量时段 / 转化漏斗 / RFM 分层 / Cohort 留存 / 品类 Top）、项目贡献
4. 能力板块：5 项能力卡片
5. 方法板块：5 条方法论
6. 证据板块：4 个图表占位卡（DAU、漏斗、RFM、Cohort）+ 报告说明卡
7. 页脚：姓名、学校、求职意向、返回顶部锚点

## 视觉

- accent #ff5a3c，accent2 #ffb547，底 #f5f5f4，卡片 #ffffff，文字 #1f2329 / #6b7280，全部写成设计 token 统一复用
- 卡片默认 1px 极淡灰边框，hover 转半透明橙边 + 橙色柔光阴影
- 关键数字大号 accent 色；无衬线、标题加粗；移动端响应式

## 技术细节

- React + Tailwind v4，token 定义在 src/styles.css，页面写在 src/routes/index.tsx
- 按板块拆成独立组件（Hero / Project / Skills / Methods / Evidence / Footer），文案与数据抽到组件顶部常量，方便你后续替换
- 占位图用本地生成的 SVG/图片文件放在 src/assets，命名对应 DAU、漏斗、RFM、Cohort，替换时直接覆盖同名文件
- head() 中设置标题、描述与 robots noindex,nofollow
