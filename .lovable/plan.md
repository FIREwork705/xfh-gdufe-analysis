# 项目板块重构：轮播卡片 + 详情弹层

其余板块（Hero / 能力 / 方法 / 页脚）保持不变，仅改造 Project，并把 Evidence 内容并入弹层。

## 数据结构

在 `src/components/portfolio/Project.tsx` 顶部定义 `projects` 数组，当前仅 1 条「淘宝用户行为分析」，文案从现有 `content.ts` 的 `PROJECT` 原样搬入，每条包含：

- 标题、一句话定位
- 关键指标 3~4 个（数值 + 标签）
- 技术栈标签数组
- 5 个分析模块（流量时段 / 转化漏斗 / RFM 分层 / Cohort 留存 / 品类 Top，各含标题 + 一句话说明）
- 我的贡献 3 条
- 证据图表说明（四张本地占位图 DAU / 漏斗 / RFM / Cohort + 口径说明文字）

## 轮播

- 封面卡固定高度，左右箭头 + 底部圆点切换
- 约 6 秒自动轮播，鼠标悬停（及键盘聚焦）暂停
- `prefers-reduced-motion` 开启时不自动轮播
- 卡片 hover：半透明橙边 + 橙色柔光（沿用现有 `pf-card` 风格）
- 仅 1 张真实卡时轮播仍可用（因为末尾追加施工中卡，共 2 张）

## 施工中卡

渲染时在数组末尾恒定追加一张「施工中…」卡：虚线边框、置灰文字、无按钮、不可点击、无链接。1 项目→2 张，2 项目→3 张。

## 详情弹层

- 真实项目卡有「查看完整分析 →」按钮，点击打开 overlay（组件内状态，非路由跳转，单页不变）
- 弹层内容：概览（定位 / 数据规模 / 技术栈标签）、5 个分析模块、我的贡献、证据图表区（四张占位图 + 报告口径说明）
- 内容超长时弹层内部滚动，外层锁定 body 滚动
- 右上角关闭按钮、点击遮罩关闭、Esc 关闭；打开时焦点进入弹层，关闭后回到触发按钮
- 圆角、边框、阴影与全站卡片一致；移动端接近全屏、桌面端居中最大宽度

## 其他改动

- `src/routes/index.tsx` 移除 `<Evidence />`
- `content.ts` 的 `NAV` 移除「证据」项（该锚点不再存在），保留 首页 / 项目 / 能力 / 方法
- `Evidence.tsx` 的图表数据与说明迁入弹层组件后删除该文件
- 占位图仍使用 `src/assets` 下现有本地 SVG，后续可直接替换同名文件

## 技术说明

- 新增 `src/components/portfolio/ProjectCarousel.tsx`（轮播 + 施工中卡）与 `ProjectModal.tsx`（弹层），`Project.tsx` 作为容器持有 `projects` 数据与选中状态
- 弹层用原生 div + `role="dialog"` `aria-modal`，不新增依赖
- 全程无外链、无表单、无第三方脚本；noindex 设置不变
